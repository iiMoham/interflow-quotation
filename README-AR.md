## الملفات

## البيانات الحالية
قاعدة البيانات تحفظ أرقام العروض فقط. مسودة العرض الحالية تحفظ في localStorage تحت interflow-current-quote. تفاصيل العملاء والمنتجات ليست في قاعدة البيانات؛ يجب استخراج المسودة من نفس المتصفح قبل النقل. مثال من Console في المتصفح: localStorage.getItem("interflow-current-quote"). لا تنقل هذه البيانات إلى أجهزة غير موثوقة.
قيمة created_at الحالية هي النص CURRENT_TIMESTAMP كما هو موجود فعليًا وليست تواريخ حقيقية؛ تم الحفاظ عليها دون اختلاق تواريخ.

## الاستيراد
استورد database.sql في قاعدة SQLite جديدة وفارغة، مثال:
sqlite3 quotation.sqlite < database.sql
بعد الاستيراد الرقم التالي هو #Qut0063. الأرقام المحجوزة لا تعني بالضرورة وجود عروض مكتملة.
هذه لقطة زمنية؛ قبل النقل النهائي أعد التصدير مع إيقاف إنشاء عروض مؤقتًا، لمنع تعارض أرقام ظهرت بعد هذه النسخة.

## رفع الموقع
المشروع الحالي Vinext / React على Cloudflare Workers ويستخدم D1 عبر binding باسم DB، وليس تطبيق Node تقليديًا جاهزًا للرفع كما هو على VPS.
للاستضافة على Cloudflare: جهز Worker وD1 جديدين، استورد SQL، وعدل إعدادات البناء والربط للنشر بحساب المطور بدل Sites.
للاستضافة على VPS: يحتاج المطور تكييف التشغيل والبناء، واستبدال cloudflare:workers وdrizzle-orm/d1 في db/index.ts باتصال SQLite على السيرفر، مع الحفاظ على API في app/api/quote-number/route.ts والتوليد الذري باستخدام AUTOINCREMENT. إعدادات .openai وbuild/sites-vite-plugin تخص البيئة الحالية وتتطلب تكييفًا.
نسخة SQL ليست MySQL؛ إذا اختار المطور MySQL/PostgreSQL عليه تحويل المخطط وآلية التسلسل.
عند إضافة حفظ كامل للعروض يجب تصميم جداول العملاء والعروض والبنود وربطها؛ لا توجد حاليًا نسخة من هذه الجداول.
